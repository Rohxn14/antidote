# Cypher reference

Generated by `python -m scripts.export_cypher` from the code. Labels and relationship types come from `app/schema.py`; every `$name` is a query parameter.

## Support engine (app/support.py)

The least fixed point: one reset, then one query per round until nothing changes. This is the core algorithm, and it runs entirely inside FalkorDB.

### reset

```cypher
MATCH (s:Source)
SET s.valid = (s.trust <> $quarantined)
WITH count(*) AS sources
MATCH (j:Justification)
SET j.holds = false
WITH count(*) AS justifications
MATCH (n) WHERE n:Belief OR n:Decision
SET n.valid = false
```

### round

```cypher
MATCH (j:Justification)-[:PREMISE]->(p)
WHERE j.holds = false
WITH j, sum(CASE WHEN p.valid = true THEN 1 ELSE 0 END) AS valid_premises
WHERE valid_premises = j.premise_count
SET j.holds = true
WITH count(j) AS held
OPTIONAL MATCH (j:Justification)-[:SUPPORTS]->(n)
WHERE j.holds = true AND n.valid = false
WITH held, collect(DISTINCT n) AS newly_valid
FOREACH (n IN newly_valid | SET n.valid = true)
RETURN held, size(newly_valid) AS validated
```

### status

```cypher
MATCH (n) WHERE n:Source OR n:Belief OR n:Decision
RETURN n.id AS id, coalesce(n.valid, false) AS flag
UNION ALL
MATCH (j:Justification)
RETURN j.id AS id, coalesce(j.holds, false) AS flag
```

## Write path (app/memory.py)

One atomic query per logical write; each starts with MATCH on the Meta node and bumps its revision.

### add_agent

```cypher
MATCH (m:Meta {id: $meta})
MERGE (a:Agent {id: $id})
ON CREATE SET a.name = $name, a.role = $role
SET m.revision = m.revision + 1
RETURN a.id
```

### add_vendor

```cypher
MATCH (m:Meta {id: $meta})
MERGE (v:Vendor {id: $id})
ON CREATE SET v.name = $name
SET m.revision = m.revision + 1
RETURN v.id
```

### add_source

```cypher
MATCH (m:Meta {id: $meta})
MERGE (s:Source {id: $id})
ON CREATE SET s.uri = $uri, s.title = $title, s.trust = $trust,
              s.origin = $origin
SET m.revision = m.revision + 1
RETURN s.trust
```

### set_trust

```cypher
MATCH (m:Meta {id: $meta})
MATCH (s:Source {id: $id})
WITH m, s, s.trust AS before
SET s.trust = $trust, m.revision = m.revision + 1
RETURN before
```

### add_belief

```cypher
MATCH (m:Meta {id: $meta})
OPTIONAL MATCH (existing:Belief {id: $id})
WITH m, existing WHERE existing IS NULL OR existing.claim = $claim
OPTIONAL MATCH (v:Vendor) WHERE v.id IN $about
WITH m, collect(v) AS vendors
WHERE size(vendors) = size($about)
MERGE (b:Belief {id: $id})
ON CREATE SET b.claim = $claim, b.created_at = timestamp()
SET m.revision = m.revision + 1
FOREACH (v IN vendors | MERGE (b)-[:ABOUT]->(v))
RETURN b.id
```

### add_decision

```cypher
MATCH (m:Meta {id: $meta})
OPTIONAL MATCH (existing:Decision {id: $id})
WITH m, existing WHERE existing IS NULL OR existing.kind = $kind
OPTIONAL MATCH (v:Vendor) WHERE v.id IN $about
WITH m, collect(v) AS vendors
WHERE size(vendors) = size($about)
MERGE (d:Decision {id: $id})
ON CREATE SET d.kind = $kind, d.summary = $summary, d.amount = $amount,
              d.reversible = $reversible, d.state = $state,
              d.created_at = timestamp()
SET m.revision = m.revision + 1
FOREACH (v IN vendors | MERGE (d)-[:ABOUT]->(v))
RETURN d.id
```

### set_decision_state

```cypher
MATCH (m:Meta {id: $meta})
MATCH (d:Decision {id: $id})
WITH m, d, d.state AS before
SET d.state = $state, d.note = $note,
    d.approved_by = coalesce($approved_by, d.approved_by),
    m.revision = m.revision + 1
RETURN before
```

### add_justification (for a belief)

```cypher
MATCH (m:Meta {id: $meta})
MATCH (t:Belief {id: $supports})
OPTIONAL MATCH (dup:Justification {id: $id})
WITH m, t, dup WHERE dup IS NULL
OPTIONAL MATCH (a:Agent {id: $agent})
WITH m, t, a WHERE $agent IS NULL OR a IS NOT NULL
UNWIND $premises AS pid
OPTIONAL MATCH (ps:Source {id: pid})
OPTIONAL MATCH (pb:Belief {id: pid})
WITH m, t, a, collect(coalesce(ps, pb)) AS found
WHERE size(found) = size($premises)
CREATE (j:Justification {id: $id, kind: $kind, reasoning: $reasoning,
                            quote: $quote, model: $model,
                            premise_count: size($premises),
                            created_at: timestamp()})
CREATE (j)-[:SUPPORTS]->(t)
FOREACH (p IN found | CREATE (j)-[:PREMISE]->(p))
FOREACH (x IN CASE WHEN a IS NULL THEN [] ELSE [a] END |
         CREATE (x)-[:AUTHORED]->(j))
SET m.revision = m.revision + 1
RETURN j.id
```

### add_justification (for a decision)

```cypher
MATCH (m:Meta {id: $meta})
MATCH (t:Decision {id: $supports})
OPTIONAL MATCH (dup:Justification {id: $id})
WITH m, t, dup WHERE dup IS NULL
OPTIONAL MATCH (a:Agent {id: $agent})
WITH m, t, a WHERE $agent IS NULL OR a IS NOT NULL
UNWIND $premises AS pid
OPTIONAL MATCH (ps:Source {id: pid})
OPTIONAL MATCH (pb:Belief {id: pid})
WITH m, t, a, collect(coalesce(ps, pb)) AS found
WHERE size(found) = size($premises)
CREATE (j:Justification {id: $id, kind: $kind, reasoning: $reasoning,
                            quote: $quote, model: $model,
                            premise_count: size($premises),
                            created_at: timestamp()})
CREATE (j)-[:SUPPORTS]->(t)
FOREACH (p IN found | CREATE (j)-[:PREMISE]->(p))
FOREACH (x IN CASE WHEN a IS NULL THEN [] ELSE [a] END |
         CREATE (x)-[:AUTHORED]->(j))
SET m.revision = m.revision + 1
RETURN j.id
```

### record_repair

```cypher
MATCH (m:Meta {id: $meta})
MATCH (s:Source {id: $source})
CREATE (r:Repair {id: $id, created_at: timestamp(),
                     approved_by: $approved_by, revision: $revision})
CREATE (r)-[:TARGETED]->(s)
SET m.revision = m.revision + 1
WITH r
UNWIND $changes AS c
MATCH (n {id: c.id}) WHERE n:Belief OR n:Decision
CREATE (r)-[:CHANGED {before: c.before, after: c.after}]->(n)
RETURN count(n)
```

### valid_beliefs

```cypher
MATCH (b:Belief) WHERE b.valid = true
OPTIONAL MATCH (b)-[:ABOUT]->(v:Vendor)
WITH b, v WHERE $vendor IS NULL OR v.id = $vendor
RETURN b.id, b.claim, v.id, v.name
ORDER BY b.id
```

## Action gate (app/gate.py)

Reads the order on the current graph; the what-if queries run on a throwaway GRAPH.COPY to test robustness to losing a trusted origin.

### read decision

```cypher
MATCH (d:Decision {id: $id})
RETURN d.kind, d.amount, d.reversible, d.state, d.valid = true, d.approved_by
```

### trusted origins

```cypher
MATCH (s:Source) WHERE s.trust = $trusted
RETURN DISTINCT s.origin ORDER BY s.origin
```

### what-if: remember trust

```cypher
MATCH (s:Source) SET s.real_trust = s.trust
```

### what-if: scenario

```cypher
MATCH (s:Source)
SET s.trust = CASE WHEN s.real_trust = $trusted AND NOT (s.origin IN $removed)
                   THEN $trusted ELSE $quarantined END
```

## Repair preview (app/repair.py)

Run on a GRAPH.COPY: snapshot the flags, quarantine, recompute, then diff with Cypher.

### snapshot conclusions

```cypher
MATCH (n) WHERE n:Belief OR n:Decision
SET n.was_valid = coalesce(n.valid, false)
```

### snapshot justifications

```cypher
MATCH (j:Justification)
SET j.was_holding = coalesce(j.holds, false)
```

### lost

```cypher
MATCH (n) WHERE (n:Belief OR n:Decision)
  AND n.was_valid = true AND n.valid = false
RETURN n.id, labels(n)[0], coalesce(n.claim, n.summary), n.kind, n.state, n.amount
ORDER BY n.id
```

### survived

```cypher
MATCH (gone:Justification)-[:SUPPORTS]->(n)
WHERE gone.was_holding = true AND gone.holds = false AND n.valid = true
MATCH (kept:Justification)-[:SUPPORTS]->(n)
WHERE kept.holds = true
MATCH (kept)-[:PREMISE]->(p)
RETURN n.id, coalesce(n.claim, n.summary), kept.id, kept.kind, collect(DISTINCT p.id)
ORDER BY n.id, kept.id
```

### source trust

```cypher
MATCH (s:Source {id: $id}) RETURN s.trust
```

## Read-only views (app/views.py)

Used by the UI and the MCP tools.

### nodes

```cypher
MATCH (n) WHERE n:Source OR n:Belief OR n:Decision OR n:Justification
OPTIONAL MATCH (n)-[:ABOUT]->(v:Vendor)
RETURN n.id, labels(n)[0], coalesce(n.claim, n.summary, n.title, n.reasoning),
       coalesce(n.valid, n.holds, false), n.trust, n.kind, n.state, collect(v.id)
```

### edges

```cypher
MATCH (j:Justification)-[r]->(x)
RETURN j.id, type(r), x.id
```

### why

```cypher
MATCH (n) WHERE n.id = $id AND (n:Belief OR n:Decision)
MATCH (n)<-[:SUPPORTS]-(j:Justification)
OPTIONAL MATCH (a:Agent)-[:AUTHORED]->(j)
OPTIONAL MATCH (j)-[:PREMISE]->(p)
RETURN j.id, j.kind, coalesce(j.holds, false), j.reasoning, j.quote, j.model,
       a.name, collect(p.id)
ORDER BY j.id
```

### decisions

```cypher
MATCH (d:Decision)
OPTIONAL MATCH (d)-[:ABOUT]->(v:Vendor)
RETURN d.id, d.kind, d.summary, d.amount, d.state, coalesce(d.valid, false),
       d.note, d.approved_by, v.name
ORDER BY d.kind DESC, d.id
```

### repairs

```cypher
MATCH (r:Repair)-[:TARGETED]->(s:Source)
OPTIONAL MATCH (r)-[c:CHANGED]->(n)
RETURN r.id, r.approved_by, r.revision, s.id, s.title, collect(n.id)
ORDER BY r.revision
```

## Schema (app/schema.py)

`ensure_schema()` runs `MERGE (m:Meta {id: 'graph'}) ON CREATE SET m.revision = 0`, then
creates the range indexes that do not exist yet (FalkorDB raises on duplicates):

```cypher
CREATE INDEX FOR (n:Source) ON (n.id)
CREATE INDEX FOR (n:Belief) ON (n.id)
CREATE INDEX FOR (n:Decision) ON (n.id)
CREATE INDEX FOR (n:Justification) ON (n.id)
CREATE INDEX FOR (n:Agent) ON (n.id)
CREATE INDEX FOR (n:Vendor) ON (n.id)
CREATE INDEX FOR (n:Repair) ON (n.id)
CREATE INDEX FOR (n:Meta) ON (n.id)
CREATE INDEX FOR (n:Vendor) ON (n.name)
```

Graph copies use the `GRAPH.COPY` command (falkordb client: `graph.copy(name)`) for the
repair preview, the gate's what-if tests, per-visitor demo graphs and the rollback baseline.
